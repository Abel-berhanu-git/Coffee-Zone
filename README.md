# ☕ Coffee Zone – Discover the Aroma of Freshly Brewed Coffee

Coffee Zone is a modern, responsive static website showcasing Ethiopian coffee culture, products, and the rich heritage behind every cup.  
It is built using **HTML, CSS, and JavaScript**, and deployed on **Netlify**.

---

## 🚀 Live Demo

👉 **Visit the live website:**  
🌍 Live Site: <a href="https://coffee-zone-et.netlify.app" target="_blank">https://coffee-zone-et.netlify.app</a>

---

## 📌 Features

- ☕ Beautiful, coffee-themed landing page  
- 📱 Fully responsive design (mobile-first)  
- ⚡ Lightweight and fast static website  
- 🎨 Clean UI with modern typography and visuals  
- 🛒 Product-style cards for coffee items  
- 🌐 Simple and user-friendly layout

---

## 🛠️ Technologies Used

- **HTML5**  
- **CSS3 (using float)**  
- **JavaScript (optional interactions)**  
- **Netlify (deployment)**
